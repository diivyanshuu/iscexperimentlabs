# ISC Labs

**Free, open-source 3D virtual labs for Class 12 Physics and Chemistry practicals (ISC , India).**

Many students prepare for practical exams without ever handling the apparatus: their school has no proper lab, too little equipment, or too many students per bench. ISC Labs lets them do the experiment on screen. Set up the apparatus, change the values, take readings, make mistakes, and repeat it until the procedure makes sense. It runs in a browser, including on a phone, and is free.

I'm a teacher and graphic designer from Surat, Gujarat, and I built this for my own students first.

## What's inside

- **12 Physics experiments** (electricity and optics)
- **24 Chemistry pages**: 22 experiments (titrations, kinetics, organic tests, salt analysis) plus two exam simulators, *Salt Analysis Exam* and *Identify the Unknown*
- Interactive 3D apparatus, a step-by-step guide window and a live lab-state window in every lab
- Each lab is a single self-contained HTML file. No install, no account, no build step

## Try it

Open [`index.html`](index.html) in a browser, or host the repo on GitHub Pages (Settings, Pages, deploy from the `main` branch) and share the link with your class.

Free study notes and the main student portal: <https://ad5253.github.io/isc>
